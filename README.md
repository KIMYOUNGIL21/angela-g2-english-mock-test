# 안젤라 선생님 고2 영어 기출 변형 Set 01

안젤라 선생님 1:1 영어 수업용 고2 진단 테스트입니다. 학생용 문제지와 교사용
정답·해설을 서로 다른 페이지로 분리했습니다.

## 공유 페이지

- 학생용 문제지. <https://kimyoungil21.github.io/angela-g2-english-mock-test/>
- 교사용 정답 및 해설.
  <https://kimyoungil21.github.io/angela-g2-english-mock-test/answers.html>

학생에게 전달할 때는 학생용 URL만 공유하세요. 교사용 답지는 별도 URL이지만
비밀번호로 보호되는 페이지는 아닙니다.

## 문항 구성

- 어휘 1문항, 어법 2문항, 독해 7문항.
- 난이도 하 3문항, 중 4문항, 상 3문항.
- 5지선다형 10문항, 권장 시간 25분.
- 학생용 페이지에는 정답과 난이도를 표시하지 않습니다.
- 교사용 페이지에는 빠른 정답표, 정답 근거, 오답 해설, 핵심 어휘, 수업 포인트,
  참고 기출 링크를 표시합니다.

## 기출 참고 방식

EBSi 원문을 복제하지 않았습니다. 2024~2025년 고2 전국연합학력평가의 핵심
논리와 출제 유형을 참고해 지문과 선택지를 새로 쓴 창작 변형문항입니다. 각 문항의
공식 문제지·해설 링크와 변형 범위는 교사용 답지에 기록했습니다.

## 로컬 확인

```powershell
npm start
```

브라우저에서 `http://localhost:8080/`과
`http://localhost:8080/answers.html`을 확인합니다.

## 테스트

```powershell
npm test
```

테스트는 문항 수, 영역·난이도 분포, 문제와 정답의 연결, 오답 해설, EBSi 출처,
학생용·교사용 데이터 분리, 안젤라 선생님 브랜드 표시를 검사합니다.
